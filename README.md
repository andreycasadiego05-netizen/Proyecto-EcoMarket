## Descripción

EcoMarket es una plataforma web desarrollada con el propósito de promover el consumo responsable mediante la comercialización de productos ecológicos y sostenibles. El sitio ofrece una experiencia intuitiva para que los usuarios puedan explorar diferentes categorías de productos amigables con el medio ambiente, conocer sus características y contactar con la empresa para realizar pedidos o resolver dudas.

## Objetivo

Desarrollar una página web moderna y funcional que facilite la visualización y promoción de productos ecológicos, fomentando prácticas de consumo sostenibles y contribuyendo a la conciencia ambiental de los usuarios.

## Características Principales

- Catálogo de productos ecológicos.
- Filtrado por categorías.
- Diseño atractivo y responsivo.
- Sección de información.
- Formulario y medios de contacto.
- Interfaz amigable para el usuario.
- Organización clara de la información.

## Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando las siguientes tecnologías:

- HTML5 para la estructura del sitio web.
- CSS3 para el diseño y los estilos visuales.
- GitHub para el almacenamiento y gestión del proyecto.

## Instalación y Ejecución

Para ejecutar el proyecto de manera local siga los siguientes pasos:

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo index.html.
4. Abrir el archivo en cualquier navegador web moderno.
5. Navegar por las diferentes secciones de la página.

No se requiere instalación de dependencias adicionales debido a que el proyecto fue desarrollado con tecnologías web básicas.

## Funcionalidades

### Catálogo de Productos
Permite visualizar los productos ecológicos disponibles junto con información relevante como nombre, descripción, categoría y precio.


### Filtros por Categoría
Permite organizar y visualizar productos según la categoría seleccionada por el usuario.

### Sección Sobre Nosotros
Presenta información sobre la misión, visión y compromiso ambiental de EcoMarket.

### Contacto
Ofrece diferentes medios de comunicación para que los usuarios puedan realizar consultas o solicitudes.

## Beneficios del Proyecto

- Promueve hábitos de consumo sostenible.
- Facilita el acceso a productos ecológicos.
- Mejora la experiencia de navegación de los usuarios.
- Presenta una interfaz moderna y organizada.
- Contribuye a la difusión de prácticas responsables con el medio ambiente.
